# 🚀 Universal Linux Server Health & Security Diagnostics

Универсальный Bash-скрипт экспресс-диагностики состояния VPS/VDS серверов под управлением **Ubuntu / Debian**. 

Скрипт автоматически обнаруживает установленные утилиты, собирает метрики системы, диагностирует контейнеры Docker, проверяет состояние БД PostgreSQL, ищет SSL-сертификаты и выводит сводку безопасности (SSH-атаки, Fail2ban).

---

## ✨ Возможности скрипта

* 🖥 **Системные метрики:** Uptime, загрузка процессора, оперативная память, свободное место на дисках (без системных `tmpfs`).
* 🐳 **Docker & Containers:** Вывод списка всех контейнеров, их потребление RAM/CPU, умная фильтрация логов на наличие ошибок (`error`, `warn`, `fail`).
* 🐘 **PostgreSQL (Docker):** Автоматический поиск контейнера с Postgres, проверка подключения, вывод списка БД и активных соединений.
* 🔒 **Безопасность:**
  * Анализ неудачных попыток входа по SSH (работает как с `/var/log/auth.log`, так и с `systemd-journald` в Ubuntu 24.04+).
  * Инспекция **Fail2ban**: автоматическое обнаружение, статус джейлов (jails) и списки заблокированных IP.
  * Проверка пользователей с привилегиями `sudo`.
  * Проверка доступных обновлений `apt`.
* 📜 **SSL-сертификаты:** Поиск и вывод сроков годности сертификатов Let's Encrypt / Certbot.

## ⚡️ Быстрый запуск

### 1. Запуск одной командой (без скачивания)
```bash
curl -sSL [https://raw.githubusercontent.com/ВАШ_USERNAME/ВАШ_РЕПОЗИТОРИЙ/main/server_diag.sh](https://raw.githubusercontent.com/ВАШ_USERNAME/ВАШ_РЕПОЗИТОРИЙ/main/server_diag.sh) | bash
```

### 2. Классическая установка
```bash
# Клонирование репозитория
git clone [https://github.com/ВАШ_USERNAME/ВАШ_РЕПОЗИТОРИЙ.git](https://github.com/ВАШ_USERNAME/ВАШ_РЕПОЗИТОРИЙ.git)
cd ВАШ_РЕПОЗИТОРИЙ

# Выдача прав на исполнение
chmod +x server_diag.sh

# Запуск
./server_diag.sh
```

> 💡 **Совет:** Для полного доступа к метрикам Fail2ban, логам SSH и сокету Docker рекомендуем запускать скрипт от пользователя с правами `sudo` или добавить пользователя в группу `docker`: `sudo usermod -aG docker $USER`.

## ⚙️ Совместимость
* **ОС:** Ubuntu 20.04 / 22.04 / 24.04, Debian 10 / 11 / 12
* **Shell:** Bash 4.0+
* **Зависимости:** Не требуют обязательной установки. Если инструмент отсутствует в системе (например, Fail2ban или Docker), скрипт корректно пропустит этот блок.
