# VirtualBox CLI Manager (`vboxctl`)

Интерактивный и удобный Bash-скрипт для быстрой работы с виртуальными машинами VirtualBox через CLI (`vboxmanage`).

## Особенности
* 🖥️ **Интерактивное меню:** Навигация стрелками `↑` / `↓` и клавишей `Enter`.
* 📊 **Информация о ВМ:** Фиксированная панель со сведениями о статусе, ядрах CPU и оперативной памяти перед выбором действия.
* ⚡ **Фоновый запуск:** Запуск машин в режиме `--type headless`.
* 🛑 **Безопасное выключение:** Отправка сигнала ACPI с тайм-аутом ожидания (60 сек) и fallback-принудительным выключением.
* ⭐️ **Дефолтная ВМ:** Возможность выбрать основную машина для быстрого запуска одной командой.

## Установка

1. Склонируйте репозиторий или скачайте скрипт:
   ```bash
   git clone [https://github.com/YOUR_USERNAME/vbox-cli-manager.git](https://github.com/YOUR_USERNAME/vbox-cli-manager.git)
   cd vbox-cli-manager

```

2. Сделайте скрипт исполняемым:
```bash
chmod +x vboxctl.sh

```


3. *(Опционально)* Добавьте скрипт в `PATH` для запуска из любой точки терминала:
```bash
sudo ln -s $(pwd)/vboxctl.sh /usr/local/bin/vboxctl

```

## Использование

### 1. Интерактивный режим

Запустите скрипт без параметров, чтобы выдать список всех доступных ВМ:

```bash
./vboxctl.sh
# или 'vboxctl', если создали симлинк

```

В меню доступны следующие действия над выбранной ВМ:

* **Запустить (headless)**
* **Остановить (soft shutdown)**
* **Сделать по умолчанию**
* **Удалить машину** *(с подтверждением)*

### 2. Быстрые команды CLI

* **Запустить ВМ по умолчанию:**
```bash
vboxctl on

```


*(Сначала установите дефолтную ВМ через интерактивное меню)*
* **Безопасно выключить ВСЕ запущенные ВМ:**
```bash
vboxctl off

```
