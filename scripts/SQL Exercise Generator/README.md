# SQL Exercise Generator

Bash-скрипт для автоматического создания структуры папок и файлов для SQL-упражнений.
## Описание

Скрипт создает директории и файлы для упражнений по дням обучения. Каждая директория соответствует отдельному упражнению, а внутри создается SQL-файл с соответствующим именем.

## Структура

Скрипт создает следующую структуру:

```
src/
├── ex00/
│   └── dayXX_ex00.sql
├── ex01/
│   └── dayXX_ex01.sql
├── ex02/
│   └── dayXX_ex02.sql
└── ...
```

## Установка

1. Скачайте скрипт `generate_exercises.sh`
2. Сделайте его исполняемым:
```bash
chmod +x generate_exercises.sh
```

## Использование

### Базовое использование

```bash
./generate_exercises.sh
```

### Настройка параметров

Отредактируйте переменные в начале скрипта:

```bash
# Настройки
DAY=2                    # Номер дня (0-12)
MIN=0                    # Минимальный номер упражнения
MAX=9                    # Максимальный номер упражнения
PREFIX="ex"              # Префикс для папок
FNAME_TEMPLATE="day%02d_ex%02d.sql"  # Шаблон имени файла
```

### Примеры

**Создание упражнений для SQLB3:**
```bash
DAY=2 MIN=0 MAX=10
```
Результат:
```
src/ex00/day02_ex00.sql
src/ex01/day02_ex01.sql
...
src/ex09/day02_ex10.sql
```

## Особенности

- Автоматическое определение директории `src`
- Проверка существующих папок и файлов (пропускает уже созданные)
- Защита от ошибок (проверка корректности введенных данных)
- Поддерживает любое количество упражнений
